# Mini LMS - Learning Management System

A mobile learning management system built with React Native Expo.

## Tech Stack

- React Native Expo (latest SDK)
- TypeScript (strict mode)
- Expo Router (file-based navigation)
- Zustand (state management)
- Expo SecureStore (auth token storage)
- AsyncStorage (bookmarks & app data)
- NativeWind (Tailwind styling)
- Axios (API calls)
- Expo Notifications (push notifications)
- React Native WebView (course content)

## Features

- ✅ User Authentication (Login & Register)
- ✅ Auto-login on app restart
- ✅ Course Catalog with search
- ✅ Pull to refresh
- ✅ Course Detail screen
- ✅ Bookmark courses
- ✅ WebView course content viewer
- ✅ Local notifications (5+ bookmarks)
- ✅ 24hr reminder notification
- ✅ Offline mode banner
- ✅ Profile screen with stats
- ✅ Logout functionality

## Setup Instructions

### Prerequisites

- Node.js 18+
- Expo CLI
- Expo Go app on your phone

### Installation

1. Clone the repository
   \```bash
   git clone https://github.com/nanisam07/mini-lms.git
   cd mini-lms
   \```

2. Install dependencies
   \```bash
   npm install
   \```

3. Start the app
   \```bash
   npx expo start
   \```

4. Scan QR code with Expo Go app

## Architecture Decisions

- **Expo Router** for file-based navigation (cleaner than React Navigation setup)
- **Zustand** for state management (lightweight, simple API)
- **SecureStore** for auth tokens (encrypted storage for sensitive data)
- **AsyncStorage** for bookmarks (non-sensitive persistent data)
- **Axios interceptors** for automatic token attachment and 401 handling

## API

Base URL: `https://api.freeapi.app`

| Endpoint                          | Usage             |
| --------------------------------- | ----------------- |
| POST /api/v1/users/login          | User login        |
| POST /api/v1/users/register       | User registration |
| GET /api/v1/public/randomproducts | Course data       |
| GET /api/v1/public/randomusers    | Instructor data   |

## Known Issues / Limitations

- Course data is from a public random API, so content is not real course material
- WebView shows a locally generated HTML template
- Push notifications require Expo Go or a development build
