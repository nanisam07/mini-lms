# 🚀 Mini LMS App

A modern Learning Management System (LMS) mobile app built with React Native (Expo).

## ✨ Features

- 🔐 Authentication (Login/Register)
- 📚 Course listing with search
- 🔖 Bookmark courses
- 🔔 Push notifications
- 🎯 Course detail screen
- 👤 Profile screen
- 🌐 Offline support banner
- 🎨 Premium UI (gradients, animations)

## 🛠 Tech Stack

- React Native (Expo)
- Zustand (state management)
- Axios (API)
- Expo Notifications
- Expo Router
